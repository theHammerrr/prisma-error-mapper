# Consumer integration guide

The [integration guide](../skills/use-prisma-error-mapper/references/integration-guide.md)
explains how to use this package in an existing application, including named
PostgreSQL CHECK constraints, translations, and unknown-error routing.

The guide lives alongside the [consumer skill](../skills/use-prisma-error-mapper/SKILL.md)
so copying the skill also copies its reference material. There is only one maintained
copy of the guide. Both are included in the npm tarball.

See the [README](../README.md#coding-agent-integration) for installation and invocation.
